# VeriPay

**[AGENTS.md](./AGENTS.md) is the source of truth** for repository structure,
commands, architectural boundaries, domain rules and test expectations. Read it
before making changes.

The four rules worth repeating here, because getting them wrong is expensive:

1. **Money is integer minor units.** Never a float, anywhere.
2. **Auth0 authenticates; VeriPay authorizes.** A valid token is not a permission.
3. **Only signature-verified Stripe webhooks change payment state.** Never a
   client redirect.
4. **Do not deploy, commit, push, rotate credentials, run migrations, or
   provision infrastructure** without being asked in the current request.

Verify with `npm run typecheck && npm run lint && npm run test` from the root.
